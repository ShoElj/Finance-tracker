# Sound effects

The game plays a short built-in tone for every effect, so it works with no files here.
To use real sounds, add any of these MP3s to this folder:

- `break-bell.mp3`
- `snack-collect.mp3`
- `powerup.mp3`
- `caught.mp3`
- `final-bell.mp3`
- `winner.mp3`
- `button-click.mp3`

then add the file's name to `AVAILABLE_FILES` in `lib/sound.ts`.
